# МЭДО 2.0

Демонстрационный интерфейс системы электронного документооборота.

## Возможности
- экран авторизации;
- рабочий стол со статистикой;
- входящие и исходящие;
- реестр документов и поиск;
- карточки документов;
- создание проекта документа;
- поручения и отметка исполнения;
- журнал регистрации;
- организации;
- профиль, настройки и справка;
- адаптация под мобильные устройства.

## GitHub Pages
Загрузите все файлы в репозиторий GitHub, затем:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Сайт является прототипом. Сервер, база данных, реальные ЭП, авторизация и обмен документами не подключены.
